# IVA Brain

Эксперимент по созданию **собственного ядра IVA**. Проект не подключает сторонние LLM как замену IVA и не выдаёт поиск или шаблоны за нейросетевое мышление.

## IVA Brain Web

GitHub Pages: https://olgakolina71-pixel.github.io/iva-brain/

Текущий браузерный прототип включает:
- локальную память на устройстве (localStorage);
- граф знаний: сущность → отношение → сущность;
- обучение фактами через интерфейс и команду `/teach`;
- извлечение фактов из обычных утверждений с пометкой «непроверенная запись»;
- поиск по фактам и обратные запросы;
- простой вывод по цепочкам категорий (например, «кит → млекопитающее → животное»);
- контекст коротких уточнений;
- ограниченный поиск Wikipedia с указанием источника;
- просмотр следов обработки, чтобы не скрывать, как именно был получен ответ;
- экспорт/импорт локальной памяти.

### Честные ограничения

Это пока **символическое/ассоциативное когнитивное ядро**, а не языковая нейросеть. Оно не обучает веса трансформера, не имеет человеческого понимания, не проверяет автоматически истинность пользовательских утверждений и ограничено реализованными отношениями и правилами. При нехватке знаний должно признавать это, а не выдумывать.

## IVA Language (Python)

`iva_language.py` — небольшой эксперимент с обучением на примерах, фактами и поиском похожих диалогов. Запуск:

```bash
python iva_chat.py
```

Команды:
- `/teach ФАКТ` — сохранить пример/факт;
- `/learn ВОПРОС || ОТВЕТ` — добавить диалоговый пример;
- `/generate` — экспериментальная генерация из статистики переходов слов;
- `/facts`, `/memory`, `/reset`, `/help`, `/exit`.

Это retrieval/статистический эксперимент, не нейронная языковая модель.

## World-model experiments

Python 3.10+ и PyTorch:

```bash
pip install -r requirements-experiment01.txt
python -m experiments.experiment_01
python -m experiments.experiment_02
python -m experiments.experiment_03
python -m experiments.experiment_04
python -m experiments.experiment_05
python -m experiments.experiment_06
```

Эксперименты изучают:
1. Онлайн-модель переходов в sandbox.
2. Планирование по выученной модели.
3. Выбор задач через novelty/uncertainty эвристики.
4. Адаптацию при изменении среды.
5. Выделение повторяемых навыков.
6. Перенос навыков в новые карты.

Это узкие исследования и не свидетельство сознания.

## Направление разработки

1. Устойчивое представление понятий и отношений.
2. Более надёжный контекст и разрешение местоимений/коротких уточнений.
3. Проверяемый вывод, объяснения и оценка уверенности.
4. Механизмы обучения с обратной связью, с защитой от закрепления ошибочных утверждений.
5. Собственная IVA Nano языковая нейросеть — отдельный путь, который не подменяется API сторонней модели.
6. Подключение когнитивного ядра к IVA Nano, когда интерфейс и формат инференса модели будут готовы.

## Данные и безопасность

Память Web-версии локальная, на этом браузере/устройстве. Экспорт памяти создаёт JSON-файл; не включай туда секреты или персональные данные. Веб-поиск ограничен Wikipedia API и может не работать в некоторых сетях.
