# IVA Brain — Foundation (v0)

## Purpose
Build an experimental agent that acquires skills from its own interaction with an environment. It is not a chat wrapper and must not pretend that hand-written state rules constitute intelligence.

## Constraints
- No training datasets, SFT, or LoRA for the Brain project.
- Learning must happen from observations, actions, outcomes, and feedback generated during runtime.
- The IVA Nano project is separate.
- Do not claim consciousness, feelings, or general intelligence.
- Keep experiments reproducible and report what the agent actually learns.

## First research direction: online predictive learning
The initial core is a neural model that learns a predictive representation of its environment:
1. Receive observation (o_t).
2. Choose action (a_t).
3. Receive next observation (o_{t+1}).
4. Predict (o_{t+1}) (or a compact latent representation) from (o_t, a_t).
5. Compute prediction error.
6. Update model parameters online from this transition.
7. Use prediction accuracy, uncertainty, and a small environment-provided objective to evaluate future actions.

This is an experimental learning mechanism, not a claim that prediction alone yields general intelligence.

## First milestone: tiny sandbox
Create a simple, safe, fully observable environment with a small action space. The agent starts without a task-specific dataset and gathers its own transitions. Test whether it:
- learns transition dynamics from interaction;
- predicts outcomes better than a random/untrained baseline;
- uses learned predictions to choose actions more effectively;
- retains learning after restart (save model + experience state);
- can be tested against held-out states generated by the sandbox, not a training corpus.

## Architecture (initial hypothesis)
- **Perception/encoding:** convert raw sandbox observation into a compact vector.
- **Online world model:** neural network predicts next observation or latent state conditioned on action.
- **Experience store:** records observation, action, next observation, prediction, error, optional feedback.
- **Action selection:** evaluates a small candidate set using predicted outcomes, uncertainty/novelty, and environment objective. Avoid a fixed hand-written personality rule as the core.
- **Learning:** update network weights from each experience; record metrics and checkpoint.
- **Interface:** separate from the learning core; later can connect Windows, web/video, and ESP32 through permissioned adapters.

## What is explicitly not the first milestone
- YouTube or full video understanding.
- Autonomous Windows control.
- Robot/pet vacuum control.
- ESP32 physical movement.
- Claims of human-like consciousness or unrestricted autonomy.

## Evaluation
Log objective metrics: prediction loss over time, comparison with an untrained baseline, task success, exploration coverage, recovery after restart, and whether learned behavior transfers to new sandbox configurations.

## Important limitation
A system with random initial weights and no external data starts with very little capability. Learning useful behavior requires a structured environment, informative feedback, and substantial interaction. This project tests learning mechanisms incrementally; it does not assume intelligence appears automatically.
