Обучить IVA новому факту

Добавляй связи в граф знаний. Пример: «Соник это персонаж», «Соник умеет бегать», «Земля вращается вокруг Солнца». Это обучение собственной памяти и логике, не тренировка нейронных весов.

Память остаётся на этом устройстве. Экспортируй JSON, чтобы перенести её на другое.

Как IVA получает знания

1. Из явно обученных фактов. 2. Из разговора (воспоминания, не автоматическая истина). 3. Из веб-поиска (помеченные источники). 4. Из логических связей, которые она может вывести из графа.
